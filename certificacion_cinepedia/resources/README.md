# CinePedia

Aplicación web para registrar y comentar películas. Los usuarios se registran, inician sesión, publican sus películas y comentan las de otros.

**Autor:** Yoycer Garcia

## Tecnologías

Python, Flask, MySQL (PyMySQL), Jinja2, Flask-Bcrypt y python-dotenv.

## Funciones

- Registro e inicio de sesión con contraseñas encriptadas y validaciones.
- CRUD de películas: solo el creador puede editarlas o borrarlas.
- El nombre de cada película es único.
- Comentarios en películas ajenas, con opción de borrar los propios.
